# 4.4 데이터베이스의 종류
## 4.4.1 관계형 데이터베이스
- 데이터를 테이블 형태로 저장하는 데이터베이스 모델
- 각 테이블은 행과 열로 구성되며, 행은 레코드(Record)를 나타내고, 열은 필드(Field)를 나타냄.
- 테이블 간의 관계는 외래 키(Foreign Key)를 통해 표현
- 예시: MySQL, PostgreSQL, Oracle Database 등

## 4.4.2 NoSQL 데이터베이스
- 관계형 데이터베이스와 달리, 데이터를 비정형적으로 저장하는 데이터베이스 모델
- 다양한 데이터 모델을 지원 (문서 지향, 키-값, 그래프 등)
- 대규모 데이터 처리와 높은 확장성을 제공
- 예시: MongoDB(문서 지향), Redis(키-값), Neo4j(그래프) 등

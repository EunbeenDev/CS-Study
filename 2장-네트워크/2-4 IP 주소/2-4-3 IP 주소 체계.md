### IP 주소 체계
- **클래스 기반 할당 방식**
    - IP 주소를 A, B, C, D, E 클래스로 구분
    - 네트워크/호스트 영역을 고정적으로 분리
    - 주소 낭비 문제로 현재는 거의 사용되지 않음

- **DHCP(Dynamic Host Configuration Protocol)**
    - IP 주소를 자동으로 할당해주는 프로토콜
    - IP 주소, 서브넷 마스크, 게이트웨이 정보 제공

- **NAT(Network Address Translation)**
    - 사설 IP 주소를 공인 IP 주소로 변환
    - IP 주소 절약 및 내부 네트워크 보안 강화

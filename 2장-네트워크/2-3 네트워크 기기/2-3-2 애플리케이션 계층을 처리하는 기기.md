
### 애플리케이션 계층을 처리하는 기기

#### L7 스위치
- HTTP, HTTPS 등 애플리케이션 계층 데이터 기반 트래픽 제어
- URL, 헤더, 쿠키 등을 기준으로 로드 밸런싱 가능

>#### L4 스위치 vs L7 스위치
>- L4 스위치: IP, 포트 번호 기반 트래픽 분산
>- L7 스위치: 애플리케이션 계층 정보 기반 트래픽 분산
---
#### 헬스 체크 (Health Check)
- 서버의 상태를 주기적으로 확인하여 정상 서버만 트래픽 전달
- L7, L4 스위치 모두 헬스 체크를 통해 정상/비정상적인 서버를 판별한다.
- 전송 주기화 재전송 횟수 등을 설정한 뒤 반복적으로 서버에 요청을 보내서 서버 상태를 확인
  - 이때 서버에 부하가 되지 않을 만큼 요청 횟수가 적절해야 한다.

#### 로드 밸런서를 이용한 서버 이중화
- 로드 밸런서는 2대 이상의 서버를 기반으로 가상 IP를 제공하고 이를 기반으로 안정적인 서비스를 제공
- 여러 서버에 트래픽을 분산하여 장애 발생 시 서비스 연속성 보장

### 인터넷 계층을 처리하는 기기
#### 1. 라우터
- IP 주소를 기반으로 서로 다른 네트워크 간에 패킷을 전달하는 장치
- 목적지 IP를 확인하여 **최적의 경로(Route)**를 결정
- 가정용 공유기부터 ISP 백본 네트워크까지 폭넓게 사용됨
- 역할 
  - 네비게이션 역할
  - 네트워크와 네트워크 연결 
  - 패킷이 이동할 다음 목적지 결정

#### 2. L3 스위치
- 스위칭 기능(L2)과 라우팅 기능(L3)을 함께 수행하는 장치 
- 내부 네트워크에서 고속 IP 기반 패킷 처리 가능 
- 사내 네트워크 환경에서 주로 사용됨
- 특징 
  - 라우터보다 빠른 처리 속도 
  - 대규모 내부 트래픽 처리에 적합

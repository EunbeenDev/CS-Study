# CS 스터디
[![Since](https://img.shields.io/badge/since-2026.01.21-333333.svg?style=flat-square)](https://github.com/EunbeenDev/CS-Study)

CS 전공 지식에 관한 스터디 내용을 담은 저장소입니다.
## 스터디 사용 책
본 스터디는 [[면접을 위한 CS 전공지식 노트, 주홍철 저]](http://www.yes24.com/Product/Goods/108887922) 책을 기준으로 진행됩니다.

## 스터디 목표
- CS 기본 지식들을 깊이 있게 습득한다.
- 알고 있는 내용을 명확하게 전달하는 연습을 한다.
- 개념을 논리적으로 정리하고 타인에게 설명할 수 있는 수준까지 끌어올린다.

## 진행 방식
### 1. 스터디 일정
- **매주 수요일 14:00-15:30** (공휴일일 경우, 다른 날로 대체될 수 있습니다.)
- 디스코드 채널에서 온라인으로 진행됩니다.
### 2. 스터디 준비
- 각 장의 내용을 1주에 걸쳐 학습합니다. __(섹션의 내용이 방대해질 경우, 유동적으로 섹션을 분리하여 진행합니다.)__
- 각 스터디원은 해당 주에 학습하는 내용에 대해 아래 내용을 준비해 와야 합니다.
    - 해당 주차의 스터디 범위를 각자 공부하고 내용을 정리한 후 깃에 업로드합니다. __(형식은 자유입니다.)__

### 3. 발표 진행 방식
- 매 스터디 모임마다 정해진 섹션별로 발표할 사람이 랜덤으로 정해집니다 (예: 사다리 타기).
- 매 스터디 모임마다 한 사람이 발표한 후, 다른 사람들이 발표자에게 질문하는 식으로 진행됩니다.
- 스터디 진행 내용을 본 저장소에 기록하여 저장합니다. 기록하는 내용과 방식은 아래와 같습니다.
    - 해당 주차의 발표 내용과 발표자를 기록합니다.
    - 스터디 중 발생한 QnA는 질문을 받은 발표자가 해당 [issues](https://github.com/EunbeenDev/CS-Study/issues)에 기록합니다.
    - 발표한 내용에 추가 혹은 보완할 내용이 있다면, 스터디 이후 자유롭게 PR 기능을 통해 적용할 수 있습니다.
- 기본적으로 모든 내용은 책을 바탕으로 합니다.
    - 책에 나오는 내용 외에 추가적인 내용을 다루는 경우, 명확한 출처와 근거 자료를 제시해야 합니다. (잘못된 내용을 학습하는 것을 막기 위함)


## 1-2-1. 선언형과 함수형 프로그래밍

### 선언형 프로그래밍 (Declarative Programming)

* **무엇을 할 것인가**에 집중하는 프로그래밍 방식
* 수행 과정(How)을 직접 명시하지 않는다

#### 특징

* 상태 변경을 최소화
* 읽기 쉽고 의도가 명확
* 내부 동작은 시스템에 위임

#### 예시

```java
list.stream()
    .filter(n -> n > 10)
    .map(n -> n * 2)
    .toList();
```

> "어떻게 반복하는지"보다 "무엇을 필터링하고 변환할지"를 표현

---

### 함수형 프로그래밍 (Functional Programming)

* **함수를 1급 객체**로 다루는 프로그래밍 패러다임
* 순수 함수와 불변성을 핵심으로 한다

#### 핵심 개념

* 순수 함수 (Pure Function)
* 불변성 (Immutability)
* 부수 효과(Side Effect) 최소화
* 고차 함수 (Higher-order Function)

#### 장점

* 테스트 용이
* 병렬 처리에 유리
* 예측 가능한 코드

#### 단점

* 러닝 커브
* 상태 기반 로직 표현이 어려울 수 있음

---

### 선언형 vs 함수형

| 구분 | 선언형             | 함수형                 |
| -- | --------------- | ------------------- |
| 초점 | 무엇을 할지          | 계산을 함수로 표현          |
| 상태 | 숨김              | 불변                  |
| 예  | SQL, Stream API | map, reduce, lambda |

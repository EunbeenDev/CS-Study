
## 1-1-7. 노출 패턴 (Facade Pattern)

### 1. 노출 패턴이란?

* 복잡한 서브 시스템을 **단순한 인터페이스 하나로 감싸서 제공**하는 구조 디자인 패턴
* 클라이언트는 내부 복잡도를 몰라도 된다

> “복잡한 내부는 숨기고, 사용자는 쉬운 입구만 제공한다.”

---

### 2. 장점

* 서브 시스템과 클라이언트 간 **결합도 감소**
* 사용성 향상
* 변경 영향 범위 축소



### 3. 예시

```java
public class ComputerFacade {
    private CPU cpu = new CPU();
    private Memory memory = new Memory();
    private Disk disk = new Disk();

    public void start() {
        cpu.freeze();
        memory.load();
        disk.read();
        cpu.execute();
    }
}
```

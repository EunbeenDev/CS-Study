# 1. 운영체제와 컴퓨터
## 1.1 운영체제의 역할과 구조
### 운영체제의 역할
1. CPU 스케줄링과 프로세스 관리
   - 운영체제는 CPU 자원을 효율적으로 분배하여 여러 프로세스가 동시에 실행될 수 있도록 관리한다.
   - CPU 소유권을 어느 프로세스에게 줄지 결정하는 스케줄링 알고리즘을 사용한다.
   - 프로세스의 생성과 삭제, 자원 할당 및 반환을 관리한다.
2. 메모리 관리
   - 한정된 메모리를 어떤 프로세스에게 할당할지 결정한다.
3. 디스크 파일 관리
    - 파일 시스템을 관리하여 데이터를 저장하고 검색하는 기능을 제공한다.
4. I/O 장치 관리
    - 키보드, 마우스, 프린터 등 다양한 입출력 장치를 제어하고 관리한다.
5. 사용자 인터페이스 제공
    - 명령어 인터페이스(CLI)나 그래픽 사용자 인터페이스(GUI)를 통해 사용자가 시스템과 상호작용할 수 있도록 지원한다.

### 운영체제의 구조
- 인터페이스 커널: 유저 프로그램과 커널 사이의 인터페이스 역할
- 시스템 콜: 유저 프로그램이 커널의 기능을 호출하는 메커니즘
- 커널: 운영체제의 핵심 부분으로, 시스템 자원 관리와 프로세스 제어를 담당

운영체제는 유저 프로그램이 하드웨어 자원에 직접 접근하는 것을 방지하여 시스템의 안정성과 보안을 유지한다.  <br>
유저 프로그램은 시스템 콜을 통해 커널의 기능을 호출하여 필요한 작업을 수행한다.

### 시스템 콜 
- 운영체제가 커널에 접근하기 위한 인터페이스
- 프로세스나 스레드에서 운영체제의 서비스를 요청할 때 <br>
  시스템 콜이라는 인터페이스(추상화 계층)와 커널을 거쳐 운영체제의 기능을 사용할 수 있다.
- 유저 프로그램이 운영체제의 서비스를 받기 위해 커널 함수를 호출할 때 사용
> 시스템 콜의 흐름
>1. 유저 프로그램이 시스템 콜을 호출 (모드: 유저 모드)
>2. 시스템 콜 인터페이스가 호출을 가로채고, 커널 모드로 전환 (모드: 커널 모드 - modebit=0)
>3. 커널이 요청된 서비스를 수행 (예: 파일 읽기, 프로세스 생성, 네트워크 통신 등) (모드: 커널 모드)
>4. 결과를 유저 프로그램에 반환하고, 유저 모드로 전환 (모드: 유저 모드)
>5. 유저 프로그램이 결과를 처리하고 계속 실행 

운영체제는 시스템 콜을 통해 유저 프로그램과 커널 간의 안전한 통신을 보장한다.

### modebit
- 운영체제에서 CPU의 실행 모드(커널 모드/유저 모드)를 구분하는 비트
- 0 또는 1의 값
- 0: 커널 모드 (운영체제의 핵심 기능을 실행할 때)
- 1: 유저 모드 (일반 애플리케이션이 실행될 때)
- modebit을 통해 운영체제는 시스템 콜이 호출될 때 커널 모드로 전환하여 시스템 자원에 안전하게 접근할 수 있도록 한다.


> #### 만약 커널/유저 모드를 구분하지 않는다면?
> - 유저 프로그램이 시스템 자원에 **직접 접근**할 수 있게 되어 시스템의 안정성과 보안이 크게 위협받는다.
> - 악의적인 프로그램이 시스템 자원을 손상시키거나 다른 프로그램의 데이터를 훼손할 수 있다.
> - 운영체제가 시스템 자원을 효율적으로 관리할 수 없게 되어 전체 시스템의 성능이 저하될 수 있다.

### 커널
- 운영체제의 핵심 부분으로, 시스템 자원 관리와 프로세스 제어를 담당
- 시스템 콜을 통해 유저 프로그램과 상호작용하며, CPU 스케줄링, 메모리 관리, 파일 시스템 관리, I/O 장치 제어 등 다양한 기능을 수행
- 커널은 시스템의 안정성과 보안을 유지하는 역할을 하며, 유저 프로그램이 시스템 자원에 직접 접근하는 것을 방지한다.(modebit을 통해)

## 1.2 컴퓨터의 요소
컴퓨터는 CPU, DMA 컨트롤러, 메모리, 타이머, 디바이스 컨트롤러, 그리고 입출력 장치로 구성된다. <br>
### CPU (Central Processing Unit)
- 컴퓨터의 중앙 처리 장치로, 프로그램 명령을 해석하고 실행하는 역할을 한다.
- 연산 장치(ALU)와 제어 장치로 구성되어 있으며, 프로그램 카운터(PC)와 레지스터를 사용하여 명령어를 처리한다.
- 인터럽트에 반응하여 입출력 장치와 통신하며, 시스템 콜을 통해 운영체제와 상호작용하는 일꾼의 역할을 한다.(OS는 관리자, CPU는 일꾼)
- CPU는 시스템의 성능을 결정하는 핵심 요소로, 명령어 사이클과 클럭 속도에 따라 처리 속도가 달라진다.
- 관리자 역할을 하는 OS의 커널이 프로그램을 메모리에 올려 CPU에게 일을 시키면, CPU는 프로그램을 실행하여 결과를 반환한다.

> #### 제어장치와 레지스터
> - 제어장치: CPU 내부에서 명령어의 실행을 제어하는 부분으로, 명령어 해석과 실행 순서를 결정한다.
> - 레지스터: CPU 내부의 고속 임시 기억 장치로, 명령어 실행에 필요한 데이터를 일시적으로 저장하는 역할을 한다. 
> - CPU는 연산에 필요한 데이터를 레지스터에 저장하여 처리한다.
> - 프로그램 카운터(PC)는 현재 실행 중인 명령어의 주소를 저장하는 레지스터이다.


#### 산술 논리 연산 장치(ALU)
- CPU의 구성 요소 중 하나로, 산술 연산(덧셈, 뺄셈, 곱셈, 나눗셈)과 논리 연산(AND, OR, NOT 등)을 수행하는 장치이다.
- ALU는 CPU의 연산 능력을 담당하며, 명령어 실행 시 필요한 계산을 처리한다.
- 레지스터에 저장된 데이터를 사용하여 연산을 수행하고, 결과를 다시 레지스터에 저장하거나 메모리에 기록한다.

### CPU의 연산 처리 흐름
1. 명령어 인출 (Fetch)
   - CPU는 프로그램 카운터(PC)가 가리키는 메모리 주소에서 명령어를 읽어온다.
   - 명령어는 메모리에서 CPU로 전달되어 명령어 레지스터(IR)에 저장된다.
2. 명령어 해석 (Decode)
   - CPU의 제어장치는 명령어 레지스터(IR)에 저장된 명령어를 해석하여 어떤 연산을 수행해야 하는지 결정한다.
   - 필요한 연산과 관련된 레지스터나 메모리 주소를 식별한다.
3. 명령어 실행 (Execute)
   - ALU가 해석된 명령어에 따라 산술 또는 논리 연산을 수행한다.
   - 연산 결과는 레지스터에 저장되거나 메모리에 기록된다.
4. 프로그램 카운터(PC) 업데이트
   - 명령어 실행이 완료되면, 프로그램 카운터(PC)는 다음 명령어의 주소로 업데이트된다.
   - 일반적으로 PC는 명령어 크기만큼 증가하지만, 분기 명령어의 경우에는 명령어에 따라 다른 주소로 업데이트될 수 있다.

> #### 인터럽트 (feat. 인터럽트 핸들러 함수)
> - CPU가 외부 장치나 내부 이벤트에 반응하여 현재 작업을 일시 중단하고, 인터럽트 서비스 루틴(ISR)을 실행하는 메커니즘
> - 인터럽트는 입출력 장치에서 발생할 수 있으며, CPU가 시스템 콜을 처리할 때도 인터럽트를 사용하여 커널 모드로 전환한다.
> - 인터럽트가 발생하면? 
>   - CPU는 현재 실행 중인 작업을 저장하고
>   - 인터럽트 핸들러 함수(ISR)를 호출하여  
>   - 인터럽트에 대응하는 작업을 수행한다.(예: 입출력 처리, 시스템 콜 처리 등)
>   - 작업이 완료되면, CPU는 저장된 작업 상태로 돌아가서 이전 작업을 계속 실행한다.

### 인터럽트를 보고 어떤 작업인지 어떻게 알아내는가?
- 인터럽트 벡터 테이블: 각 인터럽트 유형에 대한 핸들러 함수의 주소를 저장하는 테이블 (예: 입출력 인터럽트, 타이머 인터럽트, 시스템 콜 인터럽트 등)
- 인터럽트 번호: 인터럽트가 발생할 때 CPU는 인터럽트 번호를 인터럽트 벡터 테이블에서 찾아 해당 핸들러 함수를 호출한다.
- 인터럽트 우선순위: 여러 인터럽트가 동시에 발생할 때, CPU는 우선순위에 따라 어떤 인터럽트를 먼저 처리할지 결정한다.


### DMA 컨트롤러 (Direct Memory Access Controller)
- CPU의 개입 없이 입출력 장치가 메모리에 직접 데이터를 전송할 수 있도록 하는 장치
- CPU가 데이터 전송에 관여하지 않으므로, CPU는 다른 작업을 수행할 수 있어 시스템의 효율성을 높인다.
- 대량의 데이터를 빠르게 전송할 때 CPU의 부담을 줄여 시스템 성능을 향상시킨다.
- DMA 컨트롤러는 입출력 장치와 메모리 간의 데이터 전송을 관리하며, CPU는 DMA 전송이 완료될 때까지 다른 작업을 수행할 수 있다.

### 메모리
- 컴퓨터 시스템에서 데이터를 저장하는 장치로, 주로 RAM(Random Access Memory)이 사용된다.
- CPU가 명령어와 데이터를 빠르게 접근할 수 있도록 하는 역할을 한다.
- 메모리는 프로그램과 데이터를 저장하며, CPU가 명령어를 실행할 때 필요한 정보를 제공한다.
- 메모리는 휘발성으로, 전원이 꺼지면 저장된 데이터가 사라진다.

### 타이머
- 컴퓨터 시스템에서 시간 관련 작업을 관리하는 장치로, 주로 CPU 스케줄링과 시스템 시간 관리를 위해 사용된다.
- 타이머는 일정한 시간 간격으로 인터럽트를 발생시켜 CPU가 특정 작업을 수행하도록 한다.
- 운영체제는 타이머 인터럽트를 사용하여 프로세스 스케줄링을 수행하고, 시스템 시간을 유지한다.

### 디바이스 컨트롤러
- 입출력 장치를 제어하는 장치로, CPU와 입출력 장치 간의 통신을 관리한다.
- 디바이스 컨트롤러는 입출력 장치의 상태를 모니터링하고, 데이터 전송을 제어하며, 인터럽트를 발생시켜 CPU에게 작업 완료를 알린다.
- 디바이스 컨트롤러는 다양한 입출력 장치(예: 하드 드라이브, 프린터, 네트워크 카드 등)를 지원하며, 각 장치에 대한 제어 명령을 처리한다.

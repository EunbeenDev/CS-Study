# 5.1 복잡도
 ## 5.1.1 시간 복잡도
- 알고리즘이 문제를 해결하는 데 걸리는 시간을 나타내는 척도
- 입력 크기에 따라 시간의 증가 정도를 나타낸다.
- 일반적으로 빅오 표기법을 사용하여 표현한다.
- 예시
  - O(1): 상수 시간 복잡도, 입력 크기에 관계없이 일정한 시간이 걸리는 알고리즘
  - O(n): 선형 시간 복잡도, 입력 크기에 비례하여 시간이 증가하는 알고리즘
  - O(n^2): 이차 시간 복잡도, 입력 크기의 제곱에 비례하여 시간이 증가하는 알고리즘
  - O(log n): 로그 시간 복잡도, 입력 크기의 로그에 비례하여 시간이 증가하는 알고리즘
  - O(n log n): 선형 로그 시간 복잡도, 입력 크기에 비례하여 로그에 비례하는 시간이 증가하는 알고리즘

## 5.1.2 공간 복잡도
- 알고리즘이 문제를 해결하는 데 필요한 메모리 공간의 양을 나타내는 척도
- 입력 크기에 따라 공간의 증가 정도를 나타낸다.
- 일반적으로 빅오 표기법을 사용하여 표현한다.
- 예시
  - O(1): 상수 공간 복잡도, 입력 크기에 관계없이 일정한 공간이 필요한 알고리즘
  - O(n): 선형 공간 복잡도, 입력 크기에 비례하여 공간이 증가하는 알고리즘
  - O(n^2): 이차 공간 복잡도, 입력 크기의 제곱에 비례하여 공간이 증가하는 알고리즘
  - O(log n): 로그 공간 복잡도, 입력 크기의 로그에 비례하여 공간이 증가하는 알고리즘
  - O(n log n): 선형 로그 공간 복잡도, 입력 크기에 비례하여 로그에 비례하는 공간이 증가하는 알고리즘


## 5.1.3 자료구조와 시간복잡도
- 자료구조는 데이터를 효율적으로 저장하고 관리하기 위한 구조로, 알고리즘의 시간 복잡도에 큰 영향을 미친다.
- 예시
  - 배열(Array): O(1) 시간 복잡도로 인덱스를 통해 요소에 접근할 수 있지만, 삽입과 삭제는 O(n) 시간 복잡도를 가진다.
  - 연결 리스트(Linked List): O(n) 시간 복잡도로 요소에 접근할 수 있지만, 삽입과 삭제는 O(1) 시간 복잡도를 가진다.
  - 해시 테이블(Hash Table): O(1) 시간 복잡도로 요소에 접근할 수 있지만, 충돌이 발생할 경우 최악의 경우 O(n) 시간 복잡도를 가질 수 있다.
  - 트리(Tree): O(log n) 시간 복잡도로 요소에 접근할 수 있지만, 삽입과 삭제는 O(log n) 시간 복잡도를 가진다.
  - 그래프(Graph): O(V + E) 시간 복잡도로 요소에 접근할 수 있지만, 탐색 알고리즘에 따라 시간 복잡도가 달라질 수 있다.
  - 힙(Heap): O(log n) 시간 복잡도로 요소에 접근할 수 있지만, 삽입과 삭제는 O(log n) 시간 복잡도를 가진다.
